<h1 align="center">WPFind</h1>

<p align="center">This searches every WordPress admin menu and submenu from one popup.</p>

## Features

- Fuzzy search across top-level and nested WordPress admin menu items
- Keyboard friendly: type to filter, use arrows to navigate, Enter to open

## Install

1. Grab `wpfind.zip` from the [Releases](../../releases) page (or clone this repository).
2. Unzip it if you downloaded the archive.
3. Open `chrome://extensions` (or `edge://extensions`).
   <img width="1334" height="992" alt="image" src="https://github.com/user-attachments/assets/9443795e-73a5-4df2-a820-34a453be3092" />

5. Enable **Developer mode**.
   <img width="761" height="694" alt="image" src="https://github.com/user-attachments/assets/2774ec66-158b-48a2-b14f-60aae768be8c" />

7. Click **Load unpacked** and select the `wpfind/` folder.
   <img width="956" height="508" alt="image" src="https://github.com/user-attachments/assets/e60b5fa8-3452-4dab-9e0c-572d9ce81f56" />

9. Open any WordPress admin page and click the WPFind toolbar icon.
