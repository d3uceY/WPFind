<h1 align="center">WPFind</h1>

<p align="center">This searches every WordPress admin menu and submenu from one popup.</p>

## Features

- Fuzzy search across top-level and nested WordPress admin menu items
- Keyboard friendly: type to filter, use arrows to navigate, Enter to open

## Install

1. Grab `wpfind.zip` from the [Releases](../../releases) page (or clone this repository).
2. Unzip it if you downloaded the archive.
3. Open `chrome://extensions` (or `edge://extensions`).
